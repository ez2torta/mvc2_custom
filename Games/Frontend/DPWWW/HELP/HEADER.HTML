"jargon: word or words", it looks up that word/phrase in the Jargon File.
"movie: movie title" it looks up that movie in The Internet Movie Database.
"actor: actor/actress name" it looks up that actor/actress in The Internet Movie Database.
"perl: keyword/function" it looks up that keyword/function in The Perl Documentation.
"cpan: module name or keywords" it does a search of CPAN for that module.
"book: book title/author" it looks up that title/author in amazon.com's database.
"cd: CD title/artist" it looks up that title/artist in amazon.
